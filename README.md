This repository contains Python lab assignments, exam preparation exercises, and programming examples completed as part of my Computer Engineering (B.Sc.) coursework at Politecnico di Torino.

📁 Repository Structure

- **laib/:** Weekly laboratory exercises (Lab 02 – Lab 11) covering core programming fundamentals, data structures, file processing, and algorithmic problem-solving.
- **Lab10-file-input/:** Dedicated module focused on complex file reading, data parsing, and string manipulation techniques.
- **exam examples/:** Practical coding challenges and previous exam problem sets to refine logic and execution under timed constraints.
- ***.txt, *.csv, *.dat:** Sample data input files located in the root directory to support direct script execution.

💡 Key Topics Covered

- **Core Fundamentals:** Logic flow, loops, functions, modular code structure, and error handling.
- **Data Structures:** Operations and optimization with lists, sets, dictionaries, and tuples.
- **File & Data Processing:** Reading, parsing, and processing structured file formats (.txt, .csv, .dat).
- **Algorithmic Problem Solving:** Designing structured solutions for practical engineering problems

🚀 How to Run

Ensure Python 3 is installed on your system. You can execute any script directly from the root directory:

python3 laib/laib2/solution.py
Note: Sample dataset files are kept in the root directory so that relative path references resolve cleanly across all lab scripts.
